# 青荷守廉｜青年廉洁文化 H5

中国银行益阳分行青年廉洁文化主题 H5。

## 内容结构

1. 员工照片
2. 员工自我介绍
3. 清廉与自身岗位相结合的感悟

当前已预留 10 位员工展示位，全部标记为“资料待发布”。

## 后续更新员工资料

在 `app/profiles.ts` 中依次补充姓名、机构、岗位、自我介绍、清廉感悟和照片路径；照片放入 `public/people/`。页面会自动同步照片墙、自我介绍和岗位感悟三个模块。

## 本地运行

```bash
pnpm install
pnpm dev
```

## 构建

```bash
pnpm build
```
